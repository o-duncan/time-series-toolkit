        Time-Series Toolkit v1

Introduction:
This project aims to be a starting point for further time-series analysis projects, and further adventures themselves. This toolkit aims to provide adequate metrics about stock pricing and financial data, to eventually be used in analysis and forecasting. Although this is not some alpha generating masterpiece, this project aims to be the vital backbone to any relevant data analysis of stocks and pricing.


The v1 Scope:
The aim is to provide cleaned datasets, showcasing simple and log returns, rolling volatility and moving averages, drawdowns and summary statistics, correlation analysis between assets and clear plots of prices and key metrics


Core Libraries Used:
pandas
numpy
matplotlib
